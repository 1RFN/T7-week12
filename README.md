Supermarket Analytics Dashboard

Aplikasi dashboard analitik penjualan supermarket berbasis PySide6, Pandas, dan Matplotlib untuk menampilkan data transaksi supermarket secara interaktif dalam bentuk tabel dan visualisasi chart.

Deskripsi Project

Project ini dibuat untuk memenuhi tugas mata kuliah pemrograman visual dengan tujuan membangun aplikasi dashboard desktop sederhana menggunakan framework PySide6.

Fitur aplikasi:
- Menampilkan data transaksi supermarket dalam bentuk tabel
- Menampilkan visualisasi data menggunakan Matplotlib
- Melakukan filter data berdasarkan cabang dan kota
- Menampilkan ringkasan statistik penjualan
- Mengekspor dashboard chart ke file PNG

Dataset yang digunakan berasal dari dataset Kaggle:
link: https://www.kaggle.com/datasets/faresashraf1001/supermarket-sales
